# McapFile

`McapFile` is a [`File`](file.md) holding an [MCAP](https://mcap.dev) robotics log.
`McapFile` and `McapSlice` rows are created by
[`read_mcap`](../datachain.md#datachain.lib.dc.mcap.read_mcap).
