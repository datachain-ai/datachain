# AI features

Studio's AI features are configured in **Team settings → AI features**.

- **[Knowledge Base](knowledge-base.md)** - AI-written pages that describe each dataset
  and storage in the team, so that agents and people can find and understand the data.
- **[MCP Server](mcp.md)** - Connect Claude Code, Claude Desktop, Codex, Cursor, and other
  MCP clients to the team's data, knowledge base, and jobs.
- **[MCP Tools](mcp-tools.md)** - What a connected agent can do: the tool list, limits,
  and example prompts.

## Getting started

1. [Enable AI and add a provider](knowledge-base.md#set-up).
2. [Generate the knowledge base](knowledge-base.md#generate-pages).
3. [Connect an agent](mcp.md#connect) and try a prompt.
